Info! NetCDF Markup Language (NcML) : Les jeux de données PAVICS sont souvent fournis par l'entremise d'agrégations NcML, une manière pratique de combiner de multiples fichiers en un seul jeu de données logique.
  • Ce que c'est : Langage de balisage basé sur XML utilisé par THREDDS pour virtualiser plusieurs fichiers NetCDF en un seul.
  • Avantage pour l'utilisateur : Remplace la gestion de dizaines de fichiers séparés (annuels ou variables) par un seul point de terminaison .ncml.
