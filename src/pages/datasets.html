ACCESS CLIMATE DATASETS

PAVICS provides data access via a THREDDS server to a growing variety of climate and weather related datasets

  • Climate simulations
  • Observations
  • Reanalyses
  • Forecasts
Info! NetCDF Markup Language (NcML): PAVICS datasets are often provided via user-friendly NcML aggregations, a convenient way to combine multiple files into a single, seamless dataset.
  • What it is: XML-based markup used by THREDDS to virtualize multiple NetCDF files as one.
  • User Benefit: Replaces managing dozens of separate yearly or variable files with a single .ncml endpoint.
